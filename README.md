# daily-morning-brief

An automated archive of a daily, unattended **Pre-Market Brief** for an
intraday options trader trading Indian index options (Nifty, Bank Nifty,
Sensex).

## How it's generated

A scheduled Claude Code cloud routine runs every weekday at **06:00 IST**.
Each run does live web research covering:

- India market trend (Nifty / Bank Nifty / India VIX)
- GIFT Nifty (implied opening level)
- US overnight close (S&P 500, Nasdaq, Dow)
- Macro/events calendar (data released overnight + scheduled for the day)

...and writes the findings to a dated brief file. No human reviews or
edits these files before they're committed — treat them as raw automated
output.

## File layout

Briefs are saved to:

```
Daily/pre-market-brief-<YYYY-MM-DD>.md
```

where the date is the IST calendar date of the trading session the brief
covers.

## Non-trading days

On weekends and NSE/BSE holidays, the routine does **not** fabricate a
brief. Instead it writes a single short line to the same `Daily/` path
noting that the market is closed and naming the next trading day, e.g.:

```
Market closed — Saturday, 05 Sep 2026 (weekend, no trading). Next trading day: Monday, 07 Sep 2026.
```

## Contents of a normal brief

Each trading-day brief has five sections:

1. **Trend** — Nifty / Bank Nifty / India VIX levels and direction
2. **GIFT Nifty** — implied opening level for the session
3. **US overnight close** — how US markets settled overnight
4. **Events calendar** — macro data/events released overnight plus what's
   scheduled for the day
5. **Bottom line** — a day-type call (**TRADE** / **CAUTION** /
   **STAND-ASIDE**) with a directional lean

## Disclaimer

This repository is an automated research digest for the account owner's
personal use only. It is **not investment advice**. Figures are
generated by an unattended AI process and may be stale, incomplete, or
wrong — always cross-check against a live market data terminal before
placing any trade.
